# Overall recommendation

## 1. 哪些先前 BLOCKED 章現在可撰寫？

- **CORE 01：READY。** 新來源已足以完成一篇明確限縮、拒絕單一 Zeitgeist 的 Vienna 1900 導讀。
- **CORE 07：READY。** SRC-023 已補足本章所需的 Western hymn 身分、拉丁文本、禮儀功能、主要語彙與 Mahler 文字配置；作者歸屬與 Mahler 私人神學仍須保留限定。
- **CORE 09、CORE 10：CONDITIONAL。** 兩章都已有足供短章使用的新證據，但 CORE 09 不得冒充首演史，CORE 10 不得冒充完整 Adorno／接受史。

## 2. 什麼仍真正 BLOCKED？

- **無。** 目前 Core 10 已沒有 BLOCKED 章；CONDITIONAL 章仍須遵守各自的敘述界線，但不妨礙 pilot drafting。

## 3. 起草前最小剩餘取得組合

**NONE — evidence acquisition gate passed.** SRC-023 已同時提供本章最低必要的 Western hymn 背景及 Mahler 文字映射。總譜／校勘報告僅在要提出精確小節、配器、聲部、反覆位置或版本異文時才成為必要證據；對目前 500–800 字文化／文本導讀只是高價值 enhancement。SRC-024 為 0-byte 空檔，不構成第二份證據。

### PHASE B explicit answers

1. **CORE 03 現在是 READY。** 現有證據足以完成短篇人物與兩部劇最低導向，不需先完成一部 Goethe 研究史。
2. **CORE 04 現在是 READY。** 原典加互相競爭的 Gillo／Trop／Hajduk／Papanikolaou 閱讀，已能負責任區分文本事實、文學詮釋、神學語彙與後來哲學框架。
3. **CORE 05 現在是 READY。** 新來源使 `Das Ewig-Weibliche` 的性別、symbol、Naturphilosophie 與 Wagner reception 層次可分開，也可和 Mahler 1909 年事後閱讀區隔。
4. **CORE 03–05 均不再真正需要另一份來源才能開始 500–800 字 drafting。** 三章的 minimum acquisition 都是 0。
5. 因此 03–05 沒有「最小必要取得」；其後的 CORE 07 最終增量更新亦已解除最後一個 blocker。
6. **High-value enhancements, not blockers：** 現代德文 *Faust I–II* 批判版；Mahler 書信學術版；Hefling 的 Justine Mahler Faust notebook 章（只在建立 Mahler genealogy 時必要）；Niekerk DOCX 的正式出版 citation；Brown、Neumann 或其他完整專論用以擴大 Goethe 爭論。Brown 不因舊書目曾列入而自動優先。

### CORE 07 explicit answers

1. **CORE 07 現在是 READY。** SRC-023 加上既有 SRC-006，足以支撐負責任的 500–800 字文本／文化導向。
2. **CONDITIONAL 不適用。** 寫作者仍須把 Hrabanus Maurus 的作者歸屬寫成有根據但未確定的歸屬，不把讚歌神學等同 Mahler 私人神學，也不聲稱兩部分自始共同規劃。
3. **BLOCKED 不適用；必要新增取得為 0。**
4. **Mahler VIII 總譜／校勘報告不是 blocker，而是 high-value enhancement。** 精確逐小節、配器、聲部、反覆與版本判定才需要它；本章不需要這些主張。Bauer 已提供足以核對 Mahler 實際設定文字的逐節映射，因此 exact stanza mapping 亦不再缺。
5. **全部 Core 10 均已充分 evidence-ready，可進入 pilot-drafting stage。** READY 章可直接起草；CONDITIONAL 章須保留現有章包所列限定，目前沒有 BLOCKED 章。
