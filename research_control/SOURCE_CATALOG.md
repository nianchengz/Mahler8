# SOURCE CATALOG

Corpus scope: every file recursively present under `sources_raw/` on 2026-09-01. The directory contains seven files and no nested subdirectories. Entries describe the actual local file, not what an older index or filename suggests it might contain.

## Status and tier vocabulary

- **FULL TEXT READABLE — TEXT LAYER:** complete local text can be searched and read.
- **FULL TEXT READABLE — IMAGE ONLY:** complete pages are visually readable, but the PDF has no usable text layer; OCR is only an audit aid and is not preserved as evidence.
- **FULL TEXT READABLE — TEXT LAYER DEFECTIVE:** the document is complete and visually readable, but extraction is unreliable; page-image consultation is required.
- **ABSTRACT/METADATA ONLY:** no local item has this status. Bibliographic records without local full text are instead listed in `MISSING_FULL_TEXT.md`.
- **T1:** primary or near-primary textual evidence. A translation remains derivative from the original language.
- **T2:** scholarship directly about Mahler VIII.
- **T3:** scholarly contextual material relevant to Mahler VIII but not direct evidence about the work's genesis or meaning.
- **T4:** later comparative/speculative or non-scholarly material. No file under `sources_raw/` is catalogued solely at T4.

The tiers express evidentiary proximity, not a universal judgment of quality.
