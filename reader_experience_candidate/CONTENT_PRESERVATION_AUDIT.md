## canonical 移除／改寫清單

此輪沒有移除具獨立論證功能的 canonical 內容。真正刪除的只有：

- 聚合打包用的 `ORIGINAL FILE` 與分隔線：非章節正文。
- 少數模板式小標「可以先記住這件事」：段落內容保留，僅改成與主問題相連的小標。
- 開頭若重複預告後文，改由具體場景承擔同一功能；原有命題仍在後段出現。

## 高風險保存點核查

- CORE 01：未把脈絡寫成直接創作成因。
- CORE 04：未讓救贖取消 Faust 責任或 Gretchen 受害史。
- CORE 05：未把 `Das Ewig-Weibliche` 固定成女人、母性、愛或單一神學實體。
- CORE 07：未把基督宗教聖靈改名成泛化「創造精神」。
- CORE 08：未用成品整合倒推兩部自創作第一刻即同時起源。
- CORE 09–10：未把巨大聲響直接等同普世代表、真誠或政治善。

## 最終判定

沒有任何一章因 Reader Experience 改寫而較 canonical 薄。CORE 05 增幅最小，是因原稿已具良好敘事線，只強化 `uns` 的主問題，不為追求長度重複堆料。
