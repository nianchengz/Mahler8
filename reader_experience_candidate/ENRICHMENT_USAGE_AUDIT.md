# Enrichment Usage Audit

## 採用原則

採用條件：能使抽象命題變成可記住的場景、能改變章節方向、能提供反例或代價，且來源層級可清楚標示。僅增加冷知識、需要跨越過多未證推論、或會破壞章界者不採。

| Chapter | 採用 enrichment | 來源 | 實際功能 |
|---|---|---|---|
| 01 | 電車／石板路／皇帝架空線；第十一誡；安靜時段與街頭管制 | SRC-010 | 把多重 Vienna 從抽象政治史變成可聽見的公共空間爭奪。 |
| 02 | Seckendorff 1782；Zelter 與 Schubert；Schumann 從終場先寫 | SRC-005 | 證明經典由片段接受長成，並讓「選哪一段」成為詮釋行動。 |
| 03 | 紙幣；Baucis「人祭」；Sorge 從鎖孔進入 | SRC-003 | 讓 Faust 的未來導向從私人欲望擴成信用、勞動、土地與誤聽。 |
| 04 | 天使玫瑰與 Mephistopheles 失手；三位悔罪者 | SRC-003, 004, 019 | 讓救贖成為多重行動者的戲劇，而非一句努力公式。 |
| 05 | `uns`；`Ewig-Leere`；天使性別／吸引的不穩定 | SRC-003, 019, 022 | 破除「女性救男性」的預設，保留終場非單一性。 |
| 06 | Berggasse 19；Adler 的鋼琴與投票；Kralik 唱歌回憶 | SRC-001 | 以真實生活關係教讀者區分接觸、友誼、政治支持與思想因果。 |
| 07 | 急電索取全文；Bauer 文本對照；兩份早期四部構想 | SRC-023, 006 | 用工作過程校正「八週神蹟」，同時深化 hymn text reading。 |
| 08 | `accende`、`superna gratia`、`ewig` 的跨部記憶 | SRC-006 | 把整合證據從抽象概念推到音樂時間，但保留譜面複核限制。 |
| 09 | `ppp wie ein Hauch`；「三首讚歌」；「我的彌撒／信經」 | SRC-006, 013, 023 | 將規模改寫成由呼吸到公共權威的動態，並歷史化類型越界。 |
| 10 | Bloch／Adorno 對照 | SRC-006, 011 | 建立能同時聽見烏托邦能力與強制整體風險的雙重耳朵。 |

## 審核後未採用或降級的材料

| 候選 | 處置 | 理由 |
|---|---|---|
| Café Central 與完整咖啡館文化場景 | 未採 | CORE 01 已有聲景主軸，再加第二套開場會分散問題。 |
| Homunculus 長段 | 未採 | 雖能深化生成／身體議題，但會使 CORE 03 故事地圖失去比例。 |
| Goethe 參與 Höhn 死刑案與 Gretchen 心理因果 | 僅留稽核 | 歷史事實可核，但由此推導創作心理的風險過高。 |
| Faust 終場「扭曲的家庭重聚」 | 未採 | Trop 的 blessed boys 身分讀法具啟發性但推測層高，不宜進核心教材。 |
| Alma／Eros 作為全作心理起源 | 未採 | 來源本身屬強詮釋，容易把婚姻心理敘事冒充 genesis。 |
| 完整 queer cosmology | 降級 | 只保留文本中 Mephistopheles／天使與 `uns` 的不穩定，框架明確歸屬 Trop。 |
| `caritas` 的完整配器／反覆分析 | 未採 | 無權威總譜與校勘報告，不能由掃描研究摘要自行擴張。 |
| 1910 首演確切人數與「千人」宣傳史 | 未採 | 本包無首演檔案，不讓規模章建立在未核實數字。 |
| Devutsky 全宇宙三元模型細節 | 未擴寫 | 英文摘要足以歸屬框架，俄文文字層不可靠；避免過度系統化。 |
| 三部 Fassbinder 電影全部再擴寫 | 保留 canonical 範圍 | 已足以證明後來接受的翻轉力，再加篇幅會使 CORE 09 偏離公共尺度主問。 |

## 使用判定

50 項候選並未追求全數塞入。正文採用 10 組、約 28 個可辨識 enrichment 點；其餘經章界、證據強度與敘事回報篩選。重大未採項均在本稽核留痕，沒有以「未寫進正文」冒充「不存在」。
